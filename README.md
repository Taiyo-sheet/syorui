# 書類（工程別 書類作成・保存）

案件くん（キントーン）の案件画面から、工程別・立場別に書類（Word / Excel / PowerPoint）の一覧を見て、
**案件の情報（案件名・住所など）を入れた書類を、その場でダウンロード**できるようにする仕組みです。
作った書類は、案件くんのその案件の「書類保管」表に、版つき（v1, v2…）で保存されます（別の保管アプリは作りません）。

## まず読むもの
- **`設定手順.md`** … 準備から動作確認まで、順番に書いてあります（非エンジニア向け）
- `レビュー報告.md` … 元のスクリプトのレビュー結果、確認したこと・していないこと、未解決の課題

## フォルダの中身
| 場所 | 中身 |
|---|---|
| `customize/doc-button.js` | 案件くんに出す「書類を作る」ボタン（画面の本体） |
| `scripts/` | アプリの自動作成、設定のバックアップ、JSの登録、通し確認、テスト用雛形づくり |
| `data/書類マスタ_初期データ.csv` | 書類マスタに最初に入れる書類（19件） |
| `customize-manifest.json` | 案件くんに登録するJSの一覧 |
| `test/` | 自動テスト（`npm test` で実行） |
| `.env.example` | 接続に使う環境変数の見本（本物のパスワードは書かないこと） |

## 状況
- 自動テスト（模擬のキントーンと、本物のブラウザ）は通っています。
- **実際のキントーンでは、まだ動かしていません。** 手順書の「確認」を見ながら、1つずつ進めてください。
- 雛形（社内の書類）は、このリポジトリに含めていません。

## 注意
- このリポジトリが公開の場合、中身は誰でも読めます。パスワード・トークン・社外秘の書類は入れないでください。

## 承認・PDF化・チェック

- 書類ごとに「承認」（承認者と日時が残る）、「書類一式を承認」、承認済みの書類の「PDF化」ができます。手順は、設定手順.md の「6」。
- 書類のチェックは、外部に送らず、画面の中だけで行います（決まったルールの確認）。
- PDF化サーバー（`pdf-server/`、LibreOffice入り）は、Render に、別のサービスとして置きます。
- 雛形の取り出し・差し替えは、`npm run template`。
